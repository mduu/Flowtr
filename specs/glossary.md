# Glossar

| Begriff | Bedeutung |
| :-- | :-- |
| **Beleg** | Quittung/Rechnung als Datei (PDF, Bild, Email), Nachweis einer Buchung. |
| **Belegnummer** | Fortlaufende Nummer, mit der ein Beleg abgelegt und umbenannt wird. |
| **Buchung** | Eine Zeile im Journal (Einnahme oder Ausgabe) mit Referenz auf ihren Beleg. |
| **Journal** | Chronologische Liste aller Buchungen (aka Milchbüchlein). |
| **Abschluss** | Abgabe eines Kalenderjahres für die Steuern; danach read-only (Archiv). |
| **Kategorie** | Gliederung der Buchungen, angelehnt an die Steuererklärung. |
| **Gegenpartei** | Lieferant bzw. Kunde einer Buchung. |
| **Dossier** | Journal + Belege eines Zeitraums, für den Treuhänder per Link (14 Tage, Code per Email) gesichert freigegeben. |
